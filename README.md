# ガムランの音階と14鍵盤

中部ジャワのスレンドロとペログを、音・音程図・鍵盤で体験するアプリです。

## 使い方

[Webアプリを開く](https://yoshs.github.io/gamelan_scale_app/)

ブラウザーでそのまま使えます。ダウンロードやインストールは不要です。

- **音階を比べる**：スレンドロ5音とペログ7音、セント値・周波数の表示、旋律の練習。
- **14鍵盤で演奏する**：音域別の鍵盤、ペログのベム／バラン切り替え、Manyarséwuの骨格旋律の自動演奏と数字譜。
- 基音は169〜369 Hzで調整でき、269 Hzに戻せます。
- スマートフォン・タブレットに対応しています。

ページ上部の切り替えリンクで、音階ページと鍵盤ページを移動できます。原譜PDFの表示にはインターネット接続が必要です。音はWeb Audio APIによる合成音です。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 公開URLから音階ページへの入口 |
| `gamelan_scale.html` | 音階の比較・練習ページ |
| `gamelan_keyboard.html` | 14鍵盤・自動演奏・譜面のページ |
| `gamelan_scale.css` | 両ページ共通のスタイル |
| `gamelan_audio.js` | 音声合成・ピッチ調整・再生処理 |
| `gamelan_scale.js` | 音階ページの操作・表示 |
| `gamelan_keyboard.js` | 鍵盤ページの操作・表示 |

調律・鍵盤配列・曲の出典は各ページに記載しています。
